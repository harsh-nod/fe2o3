This opt-in test-only observer accepts unchanged normal-driver LLVM from the seven finite composition source shapes. It runs the existing LLVM/object/LLD worker at O0/O3, without a GPU. It does not import source custody, grant protected publication, discharge host buffer bounds, or execute kernels. ## Calling-convention source inspection

The model emits internal ordinary LLVM C helpers and does not propagate source #[inline(never)], so O3 may inline a helper. The pinned AMDGPUUsage.rst non-kernel calling convention states that retained calls use scratch for a call stack; input/result physical registers and scratch/SP/return address setup belong to LLVM. VGPR32..36 are clobbered, not the listed preserved VGPR40..47 bank. The emitter gives each region explicit input constraints, early-clobber output and a scratch clobber, and restricts its operations to NoMemory U32 e32 forms. This is a sound source-level contract to submit to LLVM, not standalone proof of the backend's final allocation. Same register assignments across calls do not remove compiler ABI requirements.

No instruction/function text is rewritten, renamed, patched after linking, or used to synthesize an alternate descriptor. Old singleton, physical-entry, LDS and helper-source observers are unchanged.
