Allocator abort/OOM is not recoverable meter-unwind evidence.

## Lifetime-free proof-payload retirement

The private bridge moves checked rows, cache storage and independently owned
side tables out of a live lazy proof into an opaque retired payload. Borrowed
source/resource headers do not escape. The result has no rehydration, query,
owner or refund interface.

An exclusive empty slot is checked before debit. Twenty-one typed transfer rows
include the actual callback/result and unwind-transfer types before the live
owner is created. The owner remains outside the catch. Return/error installs
the retired payload before returning. Panic installs it and resumes the same
panic object without inserting a new returning postcheck.

This bridge does not itself place the slot in the authentic factory's pending
owner. That separate connection must preserve nested source/context postflights,
the pending-credit check, pending drop, original refund and enclosing callback
check in their original order. Component retention is not yet whole-factory
retention.
