## 1. Proposed common decision

1. Ordinary Rust plus its authenticated helper/instance closure remains the executable source. There is one actual canonical executable graph. A safety projection, observation file, source-map coordinate, checksum, descriptor or captured value is not a substitute executable or a constructor for compiler/source/launch authority.
2. Retain two explicit emission mechanisms. Bounded ordered-u32 regions use the existing constrained LLVM inline-assembly route inside ordinary functions. Closed physical-entry profiles own every entry instruction, setup and termination; verified canonical emission uses the ordinary LLVM kernel shell/metadata path. Do not treat module-assembly-only prototype failure as a continuing absence of the later working physical-body mechanism. No direct object/assembler bypass is introduced.
3. Select versions/profiles explicitly. Existing MIR32/KIR17 composition, V20, V21 and V22 owners keep their independent admission, source and wire domains. No capability-name guessing, fallback to an earlier version, relabelled decoded owner or new number allocation follows from this proposal.
4. Separate source eligibility, canonical legality, simulated semantics, conditional safety analysis, static machine observation and hardware execution. Exact native instruction matches do not prove helper ABI transport, pointer validity, general root semantics or GPU behavior. The finite normal handoffs remain inert; unresolved conditions survive all preparations.
5. Source promotion is the first editing route: exact current typed selection, checked source/HIR/Instance/SSA boundary, create-new materialization, explicit edit, then fresh ordinary frontend admission. Preserve original source and conservative possible-publication failure facts. Raw intermediate resume and assembly-to-original-Rust recovery are not provided.
6. Fixed recipes are inert bounded intent under an existing named policy. Exact/advisory constraints, applicability and explicit rebinding are checked on fresh current source. Do not expose arbitrary passes or reuse stale analysis/proof/artifact/capture evidence after a relevant edit.
7. Viewer/service state is observational and read-only by default. A logical CPU register role or SSA value is not a physical GPU register sample. Pending/symbolic, uncaptured, unsupported and ambiguous states remain explicit; stale asynchronous completion clears or refuses, never changes authority.
8. Original gfx942/gfx950, memory/collective/matrix, production, source-variant and small/tiled curriculum requirements remain in scope. A contract exit can identify pending cells with real owners and prerequisites without falsely claiming those later implementation exits complete.
