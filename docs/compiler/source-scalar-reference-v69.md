# Source-Owned Scalar Reference Consumer V69

The fixed source-owned publication route retains each registered independent CPU
reference in its existing V50 request. The inert input record is not source
authentication, a proof receipt, or execution authority. Codegen supplies the
complete original registration roster, binds each row to its authenticated
original semantic function and complete MIR body, and keeps both owners alive
until the generated request and its consumers have been retired.

## Initial Closed Contract

The initial implementation accepts rank-one original `Index1D` output carriers,
acyclic CPU `Return`/`Goto` control flow and the existing scalar expression
interpretation. CPU input loads, bounds assertions, conditional terminators,
loop summaries, checked arithmetic and other unmodeled shapes still refuse.
Every retained CPU computation must be defined; checking only the write RHS is
insufficient. The independent replay continues to validate its exact body hash,
signature, control-flow topology and both retained output lists.

Output activity is determined independently for each actual descriptor length.
There is no `point < length` premise. The proof covers zero-length outputs,
different output lengths and oversized launches. On an inactive point the
expected write list can be empty, but any observed external write then refuses.
On an active point, exact-once coverage is required separately from value and
address equality. Missing, guard-skipped, duplicated and foreign writes cannot
be excused by a conditional per-write equality.

The generated theorem concludes source definedness, successful finite return,
complete CPU computation definedness and complete output effects, then composes
with the existing same-owner V50 source-to-final relation. Source-definedness or
source/reference effect agreement is never an antecedent.

## Input Premises And Authority

The safe source contract still requires each nonempty output span to be live,
aligned and nonaliasing. These are the explicit obligations of
`DisjointSlice::from_raw_parts`, not facts created by a nominal `Index1D` type.
The original typed Rust layout selects the index mapping; it does not fulfill
the runtime span, allocation, buffer lifetime or alias obligations. Existing
retained runtime premise admission remains responsible for actual calls.

The old V50 protected runtime, resource limits, current-owner replay and exact
receipt import remain mandatory. Other source handoff policies continue to
refuse nonempty reference registrations. No-reference generated bytes are
unchanged. This work adds neither an LLVM/native theorem nor host service,
publication, loading or launch authority.

## Qualification

Ordinary tests cover expression interpretation, closed refusals, coverage source,
empty-reference byte/resource identity and exact/one-short expression and shared
text generation. Those limits do not substitute for the actual nonempty
consumer's account and custody tests. The protected shared-equation parent is distinct
from the actual registered-Rust positive and semantic-mutant parents. The latter
must execute the generated V50 proof and authenticate its receipt; source text,
an extraction-only candidate, a frontend error or a runtime setup failure does
not constitute a semantic proof result. The existing actual-source account,
foreign-ledger and unwind parent is also exercised with registered references.
All new execution obligations remain unqualified until their owning runs pass.
