and fixture tests are not substitutes for a fresh signed verifier campaign.

bodies against `self.versions.journal`. Each body performs only its corresponding
query. In particular, active lookup does not acquire the disposal-terminal gate
used by active status and the two queued queries. No query is eagerly prefetched.

The new proof root includes the complete existing queued-query execution closure.
Its journal uses the actual shared model declaration type, not another Context
schema or executable conversion. A child module separates native adapter names
from the journal's private `Root` and `Error` names. Unread versions storage,
Context, retained input root and submission identity remain arbitrary opaque
values, and the four wrappers frame those values and the complete journal. A
ghost trace records only the invoked wrapper and its exact reference argument.
It does not authenticate internal call counts, pointer identity, or hardware
observations.

This component does not yet connect the concrete wrappers to the full input
validator/fold theorem. That next composition must derive query witnesses in
specification state from actual journal decisions and reached references, not
provide executable query results as premises. The existing conditional
composition proof remains unchanged and must not be relabeled as concrete.

Live-allocation validation, fresh credit locks, Arc identity, shared interior
state, constructor reachability, allocation/unwind behavior, compiler/ISA
refinement, device ordering, performance, and HIP/HSA parity remain outside this
theorem.
