# Executable Graph Reservation Retirement

This conditional refinement compiles the same retirement suffix and concrete
retained-owner scans as `RuntimeContextV1::release_graph_v1`. It does not prove
native settlement or authorize release from an inert graph report.

## Boundary

The actual `require_graph_access(Some(token))?` prefix remains before the shared
suffix. Its successful return, the caller's original token custody, and prior
native disposal are premises outside this theorem. The source guard checks the
unchanged prefix, active module wiring, exact empty native proof annotations,
and the full 31-field Context roster. Thirty untouched fields are framed.

The shared body refuses without mutation unless the Context is nonterminal,
the exact reservation matches, issuance is closed, and every retained
submission/event/hold/issue/generated-stream/callback/backend collection is
empty. A pending replica also prevents retirement. A settled replica does not.
Success clears only the graph reservation.

Both stream scans use the actual `HashMap::values().any` operations. Named
iterator/result locals expose their state to erased proof annotations without
moving the short-circuit point. The credited replica table is dereferenced by
the same body and counted by two shared indexed loops. Opaque owner payloads,
slot incarnations, and retained resource credits remain present and unchanged.

The model uses the pinned standard-library map, iterator, slice, vector and
derived-equality contracts. Generic nominal map keys explicitly require the
existing standard-library key-model law; no new key-model axiom is introduced.
The theorem does not model allocation, destructors, thread affinity, the full
Context access gate, OS/device state, hardware completion, or backend effects.
The surrounding graph/group/replica composition remains outside this boundary.

## Maintained Qualification

`qualify-graph-reservation-retirement-v1.py` requires a clean signed source tree,
the existing exact signer and tool identities, the pinned 190-file Verus
closure, at least 16 GiB available memory, and at most 1 GiB owned evidence.
Every whole-root proof retains the existing 120-second timeout, four threads,
default SMT settings, and bounded original process-group cleanup.

It executes positive roots before and after 23 mutations, plus an exact
three-file relocated positive. Mutations alter only shared executable bodies:
each refusal predicate, error and reservation/frame update, both concrete
stream scans, optional replica handling, and replica state/count/capacity.
Timeouts, parse/type errors, omitted proof roots and uncalibrated diagnostics
are refusals, never successful negative controls. Seven source/diagnostic test
groups are construction tests, not substitutes for those solver executions.

The maintained production entrypoint runs this as an additive ninth family.
Unsigned development solver evidence is useful for review but is not a signed
production replay and does not inherit any earlier candidate's qualification.
