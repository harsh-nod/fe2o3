## What remains before normal compilation

The strict graph still needs an explicit complete-for-supported-source
boundary. Actual index/value preparation must share the original-ledger
operation namespace. Actual guarded-access construction must bind each
successful append to its exact source call and destination; volatile reads
and direct writes must not consume guarded ordinals. Only then can the
origin algorithm derive its internal consistency count from the actual
vector and authenticate every origin.

Later dereference/site construction must preserve semantic source identity,
operation insertion order and real materialization checks. Guard expansion,
Final effects, assertions, bounds, reference writes, launch binding and
source-to-ranked placement must join in one complete unverified root recipe,
followed by mandatory verification. An origin table alone supplies none of
that authority.

The next work can be drafted in parallel: narrow graph completeness,
shared index/value preparation, actual access construction/append binding,
and an independent source-rescan oracle. Integration and qualification remain
serial. General GridLeader recovery is separate; the current closed profile
must not be silently widened.

Normal helper admission remains refused. No launch permission, formal memory
safety claim, nominal LLVM continuation, GPU execution, edited-source
promotion or new milestone exit follows from this checkpoint.
