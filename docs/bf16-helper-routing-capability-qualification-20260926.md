## Implemented boundary

The production defined-call resolver now distinguishes a source-authenticated
nominal tensor helper from a scalar or local-empty helper. Its negative-only
summary and original-ledger visitor retain the actual canonical owner, inventory,
source call, independent effect report and tensor contract. The nominal route
still ends at the explicit N2c-incomplete refusal. Empty physical effects do not
establish convergence or authorize scalar treatment.

A private scoped facts adapter builds the real sparse report on the original
budget. It checks the complete retained owner/occurrence/inventory floor before
construction, refunds only its own storage, preserves additional callback
charges and sticky failures, and rejects changed ledgers or stolen floors.
Genuine Identity/Swap01 frontend sessions exercise the detailed visitor and the
actual production resolver, plus six finite whole-route boundary probes and
four isolated custody probes. Test probes prepay their bounded work and scratch
on the original phase; production limits remain unchanged.

C1 adds borrowed caller-capability authentication using the original call's
context/A/B/input-accumulator operands. The existing direct-MFMA matcher is
mechanically shared, not reimplemented with weaker rules. Source/inventory and
structural failures remain errors; only missing/incompatible origins become a
provisional capability-lattice failure. The closed helper requires actual
RowMajor source storage, even when another storage form has the same register
layout.

C3 adds a scoped association between the actual caller Call, helper Matrix and
helper Return. Its four function-qualified rows preserve Identity/Swap01 order.
A Return operand may be a transported block parameter: equality with the raw
Matrix value ID is deliberately not required. Live authenticated references,
not a digest or copied coordinates, retain the association.

The output is an ordinary **[f32; 4] array**, not an authenticated accumulator.
The exposed accumulator provenance remains the original input. Neither C1 nor
C3 creates ranked admission, normal continuation, LLVM, an artifact or launch
authority. Their new tests are synthetic mapping/origin/accounting controls;
genuine combined C1/C2/C3 propagation is still required.
