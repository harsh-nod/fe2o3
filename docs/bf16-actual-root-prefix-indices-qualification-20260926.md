# Actual retained-input root prefix and invocation indices

Status: a qualified private compiler prerequisite. Accepted broad exits remain
M1/V1/V2/U1/U2/U3 (6/18). This is not complete nominal-kernel admission.

## Implementation

A non-cloneable, higher-ranked borrowed view connects the actual retained
source owner, ranked inputs, launch and reference bindings to one pending
assembly. Its private pipeline constructor checks owner identity against
retained facts and emission data; matching cloned inputs cannot replace it.
The factory checks the complete selected source/launch/kernel-binding roster.

Ordinary compilation and bounded preparation share the existing entry-prefix
implementation: execution layout, reference constants, source-rank and axis
order, and existing partial-emission/refusal ordering are preserved. Invocation
seeding, propagation and assignment continue that same operation stream and
value-ID allocator. No zero-based component is spliced into another namespace.

The outer pending assembly owns prefix operations, reference-value IDs, rank
scratch, index tables and FIFO storage across callback/error/panic postflights.
Independent-oracle scratch is outer-owned too. Payloads are dropped before
only their accepted credits are refunded. Occupied owners and foreign ledgers
refuse. These are logical work/storage bounds, not allocator, RSS or machine
stack enforcement.

An independent genuine-source oracle rescans the complete supported-profile
graph and interprets prefix operations, IDs, index rows and FIFO entries
without calling the shared emitter, seeding, propagation or assignment routines.
It compares payloads, not only summary counts.

## Qualification

The merged regression passed 331 model tests and 2,631 backend tests
(189 ignored), plus backend/extractor build. Fourteen new unit controls cover
the shared prefix, actual namespace and connector. Five fresh Rust sessions
cover Identity, Swap01, wrong launch, callback error and callback panic.

Each of the four prepared cases reports one root, zero references/reserved
reference values, two operations, next value ID one, 31 locals, one assignment,
zero processed index edges and one FIFO entry. Whole-source alias edges need
not be reached from this invocation seed. Wrong launch refuses before prefix
preparation. Nonempty reference bindings still refuse before actual retained
source preparation; their component fixtures are inert coverage only.
Lifetime error/panic injections occur after complete prefix/index preparation,
not at every possible allocation point.

Nine preparation/control runs debit 1,911,195 logical work units for
Identity/error/panic and 1,911,519 for Swap01. Accepted handoff frames add
15,040 work/storage units: consuming continuation 10,832 and borrowed-input
view 4,208. These are measured debits, not performance improvements.

All 88 comparison controls passed. The actual lossless comparison separately
checks cumulative R16-to-R21 and direct R20-to-R21 observations. It preserves
exact keys, array order, types and numeric lexemes, all historical/current
full-stderr bindings and diagnostic positions, and the complete three
459-file/352,670,356-byte dependency closures. It also rehashes the complete
8,461-file compiled-source roster and all 350 genuine-session request inputs.

Both comparisons observe 232 differences within the same 238-path policy:

The six dependency-byte paths remain equal. Numerical results, masks,

Original-ledger replay peaks increase only by the 10,832-unit consuming frame,
from 1,632,943,151 to 1,632,953,983. Callback floors increase by both frames.
The three separately prepaid graph probes retain their exact historical peaks:
817,434,912 for Identity/error/panic and 817,435,488 for Swap01. No blanket
peak override is allowed; all other storage fields remain exact.

The comparator reserves 1,222,809,664 content-plus-EOF bytes across 10,288

and outer timeout do not prove interruption of synchronous filesystem calls.

Fresh ordinary ladders passed 36 composition and two direct-BF16 sessions.

ordinary preservation, not nominal-helper admission. The comparison itself
