storage floor before entering nested rich preparation. It runs the existing
complete-CFG induction analysis against the admitted source and original meter,
and joins the report to the exact source pointer, hash, function and identity.
There is no missing-report or empty-proof fallback.

The callback borrows the joined view with a nonescaping lifetime. Partial
reports, normal values and panic payloads are dropped before their owning
scope's refund. Postflight checks preserve callback-owned storage surplus,
cumulative work, peak storage and sticky resource denial. The production
observation hooks use the genuine caller and inventory; positive controls do
not obtain authority from a replacement ledger.
