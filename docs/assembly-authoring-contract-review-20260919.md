Proposed first source-promotion contract, drawn from actual S/N fixtures:

1. Exact gfx942:xnack-/wave64, required **and maximum** workgroup64x1x1;
   single sealed local nongeneric direct kernel; immutable u32 formal bindings.

   operator occurrences, original/normalized byte ranges and all five measured

6. Reparse the actual candidate in a new frontend. Match current types, parameter
