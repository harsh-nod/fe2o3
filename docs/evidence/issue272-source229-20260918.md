## Implementation Boundary

The existing borrowed-aggregate producer now handles an internal helper's
by-value argument zero when its first meaningful entry statement borrows the
whole aggregate. Exact, unique parameter bindings are required. Scalar fields
receive persistent private cells initialized from their incoming parameter
components; shared-slice descriptors retain their original values. Entry
initialization has a distinct source anchor. Reborrows reuse the same storage,
and references cannot outlive their owned parameter.

The independent replay checker is deliberately unchanged. It still rejects
this new entry case until it checks the caller-to-helper value transfer and
complete source/native effects. No candidate, clean effect report or component
test can replace that relation or grant artifact/launch authority.
