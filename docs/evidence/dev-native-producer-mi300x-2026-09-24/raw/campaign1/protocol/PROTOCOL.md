# Native producer-chain qualification protocol

This sibling campaign preserves the previous runtime matrix and runs only the
two appended producer witnesses. The historical twenty test names remain parser
and ignored-roster calibration inputs, not newly executed qualification results.

The input is a signed source commit containing the successful witness CPU
packet. Build preparation verifies the signer, exact Git blob/mode archive,
all 3,961 CPU source identities and the full 1,422-name runtime roster. A cold,
locked/offline all-feature musl build must pass all 1,400 CPU tests with 22
hardware-only ignores. The actual Cargo-reported test ELF is retained and hashed.

The fixed selection is GPU 1, BDF 0000:26:00.0, UID 0xab83d2ffef0d3cdf, gfx942.
Fresh native topology must confirm CPUs 0-47 and NUMA node 0. Each case needs
four GiB global/NUMA headroom, one GiB disk headroom and the unchanged strict
observer's admitted endpoint immediately before launch. A historical idle scan
or the test's explicit isolation acknowledgement is not an exclusive reservation.

Run queued producer, then published producer, one disposable process at a time.
Each exact ignored test has a 180-second TERM / five-second KILL envelope,
no core dumps, 16-MiB output-file bound and fixed CPU/NUMA affinity. Tests use
the unchanged two-launch R57 authority; no reset or native fault is requested.
Expected output requires one successful exact test, 1,421 filtered names, two
authority calls, four full-buffer digests and explicit cleanup. Each case checks
1,048,576 bytes. Publication is not a physical-overlap or performance claim.

Durably record the process group before unblocking signals. T0 follows reaping
and group absence. Regardless of test outcome, attempt strict immediate
T0+[0,1] and delayed T0+[20,21] endpoint observations. Any refusal stops the
campaign; a delayed pass cannot replace a failed immediate observation.

The local controller authenticates remote bootstrap and every payload before
execution. Collect the exact remote inventory, full ELF and all receipts before
marker-bound removal, then independently verify path/process absence. On SSH or
collection uncertainty retain the owner path for recovery; never infer process
termination from an observation timeout. The outer controller bound is 1,800
seconds. Success requires ten remote and eight local campaign commands, six
admitted endpoints, both exact witnesses and independent offline replay.

Source, toolchain, protocol and payload brackets are mandatory. Failed attempts
remain separate. No protected generated execution, physical concurrency,
fault tolerance, production-code formal refinement, aggregate-memory bound,
HIP/HSA performance parity or A1/A2 closure follows from these two witnesses.
