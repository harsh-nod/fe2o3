## Implementation

The new bounded analysis borrows the verified canonical KIR directly. For its
narrow dynamic-D1 fragment, it establishes exactly one output write on every
normal path when `global.x < output.len()`, and none on the tail. CFG joins
union possible write counts; they do not add mutually exclusive writes.
Unsupported effects, calls, loops and abnormal completion fail closed. Work
and temporary storage use the caller's cumulative verification ledger.

The result retains exact graph coordinates and an address-formation domain.
An ordinary Rust fill computes a plain, non-inbounds GEP before its guard, so
address arithmetic must be representable over the entire logical launch,
including when the output is empty. A selected-zero or output-guarded address
has a narrower domain. Neither premise is discharged by this analysis.

The generated argument-packing plan now retains its existing plan seal in
packed arguments. Its crate-private resolver reads an output's exact `u64`
slice length only after checking plan/kernel identity, argument role, physical
component, width, alignment and bounds. Packed bytes and the physical ABI are
unchanged. The resolver is not yet consumed by native host admission.

Test-only source observers use the existing import, middle, SSA and
materialization stages and borrow the actual pre-ranked canonical owner.
They do not bypass ranked admission, lower an artifact or gain launch
authority. See [the analysis and integration boundary](../conditional-output-coverage.md).

## Remaining Production Work

Total output still needs `N <= G`, exact one-dimensional execution, admitted
buffers and address representation, value refinement, and final-graph/machine
preservation. Coverage alone says nothing about the stored value: a dedicated
mutation test changes that value while preserving the coverage result.

Conditional results must be bound through the existing source-argument
correspondence, semantic contract, aggregate proof/replay and #209/#213 custody.
They must remain distinct from unconditional `total_view_proved` counts. Native
checked-output custody must reach protected publication and host admission;
only then can the existing host path discharge the exact packed-length and
launch conditions before effects. No caller-authored predicate list, parallel
graph, alternate authority gate or workload selector was added.

The source245 full-parent ownership failure remains a production blocker.
Calls, advanced numerical semantics, complete inventory joins and target-matched
hardware qualification also remain open; this slice does not turn 47 cases
into 47 completed kernels.
