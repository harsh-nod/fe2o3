## Implemented

The private `with_conditional_reference_output_v1` checks the actual pending
recipe/source association, existing canonical conditional coverage, output and
extent correspondence, ranked predicate-sensitive coverage, and exact selected
ownership occurrence. Its higher-ranked callback borrows these local facts;
they cannot escape or become a clean lowering input. No source/recipe/map clone
or new bound/staged owner field is introduced.

The CPU fragment is deliberately narrow: one flat `DisjointSlice<u32>` output,
one `usize` point argument, and one unconditional constant store followed by
normal return, optionally with a unit-return assignment. Source, adjusted ABI,
physical and raw CPU argument ordinals remain distinct. Actual Pair ABI is
accepted; tuple, hidden/context and unsupported reference shapes are refused.

The checker compares the original source/reference identities, signature,
effect digest, selected CPU write and actual required-proof subjects. It checks
the reference-side coordinate, domain, precondition and constant value against
the selected contract. Shape checks bound recursive data before equality or
canonical hashing. The 194/212-byte supported hash transcript and traversal
are charged to the original cumulative ledger. Existing storage floors remain.

The observer borrows the same reference roster used by the request producer;
it does not re-extract another roster. Existing signed-receipt allocation, order,
bytes and keys remain checked, and the protected runtime lease stays alive.
Every path still ends with the distinct `Incomplete` stop, all nine pipeline
checks pending, zero unconditional TotalView credit, existing bounds/trace
findings and residual obligations unchanged. Normal compilation is not activated.
