## Invariants

The lowerer uses the existing captured SSA live-in sets, edge arguments,
edge-specific definitions and successor ordinals. It does not introduce
another executable graph or execution-role KIR block parameter.

- Each claimed edge must match its exact retained source, ordinal, target,
  arguments and definitions. Duplicate claims and late edges reject.
- A nominal join requires all reachable predecessors and the same complete
  producer/type/context/workgroup or borrow identity. Equal ValueIds alone
  cannot establish equality. Root backedges and cyclic nominal CFGs reject.
- Ordinary components of mixed aggregates use existing scalar block parameters
  and edge coercions. Nominal leaves retain their original producer identity.
- Non-phi and empty-block pass-throughs use captured live-in state, not only
  merge variables. Moved-field masks are restored over immutable SSA archives,
  so reading a scalar sibling cannot restore a consumed capability.
- A non-phi reconstruction preserves the archived ordinary KIR type, including
  an Index carrier for a source U64. Phi components require their canonical
  transport type. Ordinary enum siblings reject rather than lose payloads.

The added structural walks, deep binding copies, type boxes, map insertion
allowances and nominal-bearing transport vectors consume the existing mutable
ledger. Type/binding walks are bounded; transparent pointer wrappers require
layout preservation and cannot erase nominal execution types. Cursor scratch
and temporary component vectors release their own reservations on success,
error and unwind. Retained copy/output allowances remain conservatively charged
for the enclosing request. This is not complete accounting of the legacy
emitter, all ordinary reconstruction, allocator overhead or process RSS.
