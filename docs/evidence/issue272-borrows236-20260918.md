## Invariant

Dereferencing an execution borrow now produces `ExecutionReferent` containing
the complete borrow record, never an owned `Execution` clone. Dereference
validation returns no owned binding. Internal clones preserve the referent
tag; ordinary scalar/SSA flattening, enum reauthentication and owned operand
transport reject it, including nested aggregates.

Reborrowing requires the actual retained assignment and exact dereferenced
reference type. It records the parent occurrence and preserves producer and
nominal type identities. Mutable access can be reborrowed as mutable or shared;
shared access cannot become mutable. Raw/fake references and mismatched types
remain rejected. These records do not prove lifetime or exclusivity.

Six new test groups cover binding identity, reborrow compatibility, emitter
dereference, attempted move-out, retained versus detached syntax, distinct
parent/child occurrences and actual root-reference substitution. Existing
flattening and enum matrices also cover the new variant. Hook fixtures retain
their explicit disclaimer: they are not admitted source/SSA owners.

## Remaining Integration

Cross-block affine availability is not implemented by this checkpoint.
`begin_block` and `edge_arguments_with_result_v1` still restore immutable SSA
bindings, while nominal moves update local bindings/tombstones. Existing
source SSA validates whole-local kills and partial moves; this is a staged
activation requirement, not an observed admitted double move.

The next connected implementation must qualify source events by call instance,
actual operand position and retained syntax identity, using existing captured
BaseUse/MoveKill/definition/storage/return-edge records and the partial-move
certificate. It must preserve legitimate sibling branches and loop
redefinitions without a global consumed set or another CFG analysis. Missing
SSA resolution is not proof. Constructor lifetimes and emission hooks must
share a charged ledger rather than clone it. Nominal phi transport, exact
provider/derive/exit custody, lifecycle verification and private checked
discharge remain required before V29 admission.
