## Remaining Integration

No unconditional `TotalView` proof counter was changed. The next production
step must retain typed source-length interpretation at view construction and
independently reconstruct it from canonical `SliceLength`, source-argument and
store correspondence. It must also reconcile global-X/index meaning and reject
conflicting interpretations of one ranked operand across views or unrelated
uses. Declaring `Argument(0)` to mean a length is insufficient.

Reference logical-ABI relations currently reside in the compiler's
`ReferenceEffectIrV1`; an opaque digest is not an independently replayable
reference preimage. Aggregate replay must consume authenticated source and
reference correspondence in the correct order. Conditional contract/evidence
successors require coordinated migration of the existing semantic contract and
frozen middle-end evidence V5, not relabeling old bytes or adding authority flags.

The host-side audit located an existing flat-ABI chain:
`validate_production_v1_semantic_root_ownership_evidence` checks ordered typed
descriptor arguments against semantic ownership; worker-V3 packing validation
checks descriptor source indices against generated fields; the new resolver
checks the exact packed owner and plan seal. A compiler-private join must still
connect the conditional binding to that same transaction's typed root. Equal
types or sizes alone cannot select a field. Ignored/tuple layouts currently
defer descriptor construction, and context forwarding requires its separately
authenticated helper/root relation, not ordinal subtraction. Descriptor V1's
contiguous source indices cannot silently become sparse original-source indices.
No descriptor wire extension is required for the current flat prerequisite,
but authenticated transport/replay of the conditional association remains open.

The conditional theorem must then survive final-graph verification, existing
#209/#213 custody, machine refinement and generated ABI reconciliation. The
normal host path must check the certified length against the actual logical
launch, address-representation domain, dimensions and memory bindings before
GPU effects, while preserving target, artifact, context and completion checks.
Advanced kernels, complete corpus binding and target-matched GPU runs remain
separate unfinished requirements.
