## Invariants

The existing shared emitter now requires ordered, complete consumption of the
captured SSA events touching declared nominal execution roots. Ordinary fields
inside those roots remain covered, even after a sibling capability is moved.

- Required rows use original block-event ordinals, not sorted lookup keys.
  Ordinary-only gaps are retained. Reachable required rows without promotion
  or resolution reject rather than disappear from the census.
- Exact source site, operand role, SSA transition, owner, instance and ledger
  checks remain in force. Whole-local Use/Kill claims commit together.
- StorageLive/StorageDead are selected by declared root, including empty and
  already-moved locals. Current runtime binding presence is not the selector.
- All required events must finish before an outgoing edge is accepted. Block
  completion requires every captured outgoing edge; function completion also
  requires every reachable block, including eventless blocks. Successor claims
  need not occur in numeric order. Entry/edge definitions remain separate.
- Projection-index events inherit their operand's nominal root. Index-only
  call destinations use the exact retained destination, without inventing a
  BaseUse. Nominal-involving elided borrows remain explicitly unsupported.
- Unhooked arithmetic, switch and assert-message reads of nominal-root scalar
  siblings fail closed. Completion detects omissions; it does not manufacture
  claims by walking source again.

The constructor reserves fixed event-index and block-range vectors on the
existing ledger. Construction is linear in captured rows/blocks; ordered claim
and completion state adds no dynamically growing vectors or second CFG.
Existing source lookup and edge census costs remain charged. This is not
complete accounting of the legacy emitter, allocator overhead or process RSS.
