Prospective correctness campaign, not a benchmark or full R126 acceptance.

It ran no queue example, was fully collected, and its exact directory was

lane count 2, 4, 8, 14 and 16, in order, through its isolated parent/child route.
Each is a metadata admission over exactly two physical queues, not a native
capacity sweep. No packets or cursor-advancing publication occur. The initial
cursor and packet/MMIO markers are source-qualified, not hardware traces.

Each case has a 180-second TERM/5-second KILL limit, no core files, 16-MiB

T0+[0,1] and T0+[20,21] seconds. Preserve both post-observation attempts.

and 3700-second local SSH bound. Only original recorded process groups may
be signalled; never signal a foreign or unverified PID.

Collect and hash-check the entire exact marked directory before removing only
it. Require original recorded PIDs/groups and accessible same-UID exe/cwd/fd/maps
references absent, rehash the remote inventory against the collected digest,
delete the exact directory, then independently recheck path/PID/group absence.
Preserve visibility limitations. Incomplete collection or unknown absence
retains the directory for controlled recovery; never unconditional cleanup.

Recovery policy, frozen before native execution:
- For marker-only setup failure, verify exact owner UID/mode/path/marker and
  absence of payload/results; inspect accessible references before removing
  that one directory. Never glob other directories.
- Loss of local SSH is not remote completion. Reconnect and poll the original
  recorded handle/launch receipt; do not restart the campaign. Wait beyond
  the remote bound before considering recovery if launch closure is missing.
- Require the exact marker, commit and payload, preserve every available result,
  and prove absence of each originally recorded group and accessible path
  reference. Never infer ownership from a current reused numeric PID.
- If the launch receipt is missing, normal cleanup remains refused. Establish
  the original launch identity from its emitted receipt and independent
  process observations before a separate reviewed recovery. Collect/hash the
  complete remaining directory before exact-path deletion and independent
  absence. If ownership or absence cannot be established, leave it intact.

This qualifies public construction and successful packetless retained teardown
only. It does not qualify submitted-work drain, logical-lane ordering/progress,
cursor advancement, native faults/panics, aggregate physical residency,
multi-device behavior, formal implementation refinement, HIP stream semantics
or HIP/HSA performance parity.
