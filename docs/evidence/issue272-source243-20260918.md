## Ownership Across Loops

Canonical V15 admission no longer rejects every cyclic CFG. The existing
forward verifier retains one exact incoming ownership state per reachable
block and checks equality on every incoming edge, including backedges and
irreducible edges. A block is processed once. Full SSA, typing and dominance
verification remain prerequisites; execution values cannot be ordinary
parameters, containers or operands.

Repeated acquisition is legal only after the same static result slot becomes
absent again. Scope end checks and clears the exact descendant roster before
restoring the context. Context issuance cannot repeat. Changed ownership,
leaks, stale descendants, live-scope calls/exits, execution phis and unreachable
execution islands remain refused. Invariant live scopes may cross backedges;
this establishes finite-path ownership, not termination or eventual disposal.

Fourteen new lifecycle tests include an independent bounded path interpreter
with generation-counted leases, sparse block orders, nested loops,
multiple-entry SCCs, switches, hostile mutations and exact/one-short resource
limits. The oracle does not reuse the production transfer/worklist algorithm.

Six new V29 discharge tests exercise checked V15 admission, existing erasure,
fresh physical V12 admission and the existing simulator. Forty-five cases
compare changing scalar phi values, nested/empty loops, output stores and
canaries with independent Rust CPU calculations. Eleven independently valid
V12 mutations of loop bounds, edges, phis, ordering, arithmetic, stores and
metadata are refused by correspondence replay. Tiles and runtime memory
authority remain unsupported by this erasure boundary.

Independent review found no finite-path soundness blocker. Additional coverage
still worth adding is a preheader-created tile/fragment carried unchanged
across a loop, and exact/one-short V29 discharge budgets on cyclic fixtures.
The lifecycle loop budgets and existing discharge budgets are tested
separately. These tests are not a universal CPU/GPU equivalence proof.

See [the discharge contract](../production-execution-discharge-v29.md) for the
inductive invariant, resource costs and production integration boundary.
