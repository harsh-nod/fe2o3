## Implemented Boundary

The pending conditional owner now rehashes its exact recipe through the original
analysis resource ledger, inheriting all earlier root-capture work, retained
storage and historical peak. Later selection, structural capture and manager
construction use the same cumulative contract. No phase restarts the budget.

Existing canonical encoders share a fallible transcript transport with the new
metered path. Infallible compatibility adapters retain old public signatures,
domains and bytes. Ranked, expression and refinement value encodings remain
distinct. Refinement fields stream fixed-size value buffers instead of allocating
temporary vectors; list padding and length framing are unchanged.

The transport pays record/byte work before SHA updates and nested insertion
before child computation. Nested hashes share one meter and account for
overlapping hash owners. Expression depth and node limits are checked during
the paid walk, not through an unmetered preflight traversal. Scratch includes
the depth-refusal frame. Unwind/error guards release scratch only after owners
drop, preserve accepted work and peak, and roll back unsuccessful output storage.
Cleanup faults prevent successful digest return. Successful digest storage remains
conservatively retained by the pending owner.

The shared helper does not duplicate recipe encoders or introduce another graph,
verification route, receipt or authority gate. Existing snapshot, epoch, complete
occurrence-roster and exact-recipe checks remain mandatory. Pending ownership
still cannot be converted into a clean lowering input.

## Resource Boundary
