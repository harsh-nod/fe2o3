# Fixed-Schema Link Parser CPU Qualification

This is CPU regression evidence, not native execution, performance acceptance,
or formal Rust/machine-code refinement. Historical evidence remains unchanged.

The fifteen-stage run binds complete before/after Cargo/source maps and the
toolchain to non-overwriting command receipts. GNU and musl use all features;
the third configuration disables default features. Each lists the complete KFD
test binary and executes the exact topology, currentness, pair-session guard,
and device-binding families (including retained-device tests matched by Cargo's
substring filter). The selected 93-name roster has a predeclared count and hash.
The six new parser tests must be present, selected
membership must match across configurations, and every selected test must pass
without skipping. The complete selected rosters are retained in `binding.json`.

Additional stages run the reviewed unsafe-source inventory (five tests plus its
explicitly ignored maintenance refresh), four verifier calibrations, scoped
formatting, and warnings-denied KFD/runtime library Clippy. Builds use two jobs,
optimization level one, no incremental/debug information, and enabled overflow
checks/debug assertions. A uniquely owned local build directory is explicit in
every Cargo command. Process closure is checked after each bounded stage.

The verifier authenticates reused receipt/source helpers before import, checks
exact commands and typed receipts, all output hashes, unchanging source/tools,
test outcomes, archive closure, and an immutable SHA-256 seal. `--live` also
compares every selected source file in the current worktree. The description
`docs/runtime-topology-link-parser-v1.md` is separately bound in the tools map.

Record once with `python3 -I -B cpu.py --record-target <owned-target-path>`.
Replay with `python3 -I -B cpu.py --live`. Failed attempts must remain visible;
never overwrite a recorded stage or remove checks to turn a failure into a pass.

Passing this packet does not establish native speedup. Currentness still reads
the complete host topology at each opening/closing boundary; only property
parsing allocation and lookup work is removed. Finer native attribution and a
matched source-to-source campaign remain outstanding.
