The old proof is captured from the correct source's **normal protected
producer/import**, not fabricated. Negative children receive only its inert
524-byte signed wire, public verification key and binding record. Each child
derives its new binding from the actual current compiler-owned refinement
request. The test observer is installed inside `after_analysis` on the actual
compiler callback thread, not around an outer thread-local rustc invocation.

For both feature-selected semantic mutations, the kernel MIR and normalized
obligation genuinely change. Feature metadata also changes portable crate/
reference identities, so the importer rejects the reference identity first.

A source hash is not the proof subject.

The original-binding reimport proves the negative was not malformed wire,
invalid signature, incompatible toolchain or exhausted importer capacity. Its
accepted proof is dropped and never supplied to the edited compiler owner.
The normal fresh wrong-source proof then really runs and fails an assertion.
No runtime-unavailable/setup failure, timeout or zero-test success is credited.

## Reproduce the proof slice

ignored `prepare_actual_source_reference_inputs` selector with
`FE2O3_TEST_ISA_REFERENCE_PREPARE_V30` pointing to a fresh absolute preparation
directory. The preparation records the actual source/cfg/argv and offline
dependencies; it does not itself execute a proof. Use the existing installed
protected runtime and freshly checked lease, not a substitute producer.

With measured absolute inputs and a new output directory:

```sh
node scripts/assembly-reference-source-v30-freshness.mjs \
  --prepared "$PROOF_PREPARED" \
  --harness "$PROOF_BACKEND_TEST" \
  --image sha256:fd5370f370708f6a02cec6d44818a4295609e5bc68aa42455e53f141168a9d5f \
  --native-volume fe2o3-authoring-proof-native-20260917-r1 \
  --output "$PROOF_FRESH_OUTPUT"
```

The variables are required prepared inputs, not discovery/fallback commands.
This test-only runner does no installation or Cargo build. Preserve failed
runs and do not invoke an unprepared child or count an empty test selection.
