## Boundary

Proof contracts cover exact ranges/cursors, failure frames, capacity-conditioned
writes, endian values and primitive round trips. They do not yet compose every
encoder capacity obligation or the complete binding/receipt wire codec. Source
guard integration changes only reviewed roster/helper pins; its older 36-,
three- and five-file executable proof closures remain unchanged.

No authentication, distributed authority, Context execution, device behavior,
performance improvement, HIP/HSA parity or A0-A7 milestone exit follows. See the
[component contract](../../runtime-distributed-codec-primitives-v1.md).
