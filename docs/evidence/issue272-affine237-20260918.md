## Invariants

`ExecutionAvailabilityV29` borrows the exact function declaration, source SSA
plan and captured occurrences selected by a helper-call instance. It reuses
the existing sorted source-event keys instead of constructing another CFG.
Equal-looking declarations or SSA plans from another owner are rejected.
Supported operand hooks require the retained operand at its actual role;
borrow hooks retain assignment identity and require source/archive agreement.

On entering a source block, the first resolved use, kill or definition for
each local determines its incoming availability. A later event cannot repair
an unavailable incoming local. A whole-local move claims its exact Use and
MoveKill once; definitions and storage kills update block-local state. Sibling
branches may independently consume their common incoming definition. A loop
that consumes a role must redefine it before the backedge. Existing source
SSA rejects the invalid-loop fixture before this consumer runs.

Nominal transport must agree with the selected SSA definition's per-instance
archive, including the complete producer/borrow identity at the selected
logical field. Matching only a ValueId or SSA ID is insufficient. Missing phi
bindings remain an error. The emitted result retains its source instance, and
the existing diagnostic correspondence builder rejects relabeling it.

Construction, event lookup and recursive aggregate classification consume the
same mutable emission ledger. Foreign ledgers are rejected before state
changes or query debits. Classification pays before descending into ordinary
prefixes, nested aggregates and enum payloads. Constructor scratch reservations
are released after success, error or unwind; escaped output rows stay charged.
The private consumer contract requires dropping the cursor without extracting
its vectors. Its higher-ranked closure signature alone does not enforce that
owned vectors cannot escape.

These are source-consistency checks, not a complete event census, ordering
proof, capability issuer, borrow-lifetime proof or admission receipt.
