## Implemented

The existing borrowed join now checks both GPU and reference coordinate, domain,
precondition and stored-value roles in one charged operation scan. Both sides
must use the supported global coordinate, true domain/precondition and exact
U32 constant from the authenticated CPU reference, with `ExactBitVector`
numerics. Shape checks precede equality. The selected GPU occurrence must be
the exact ordinary write, view, singleton index and RHS operand; another matching
write or an equal constant in another SSA operand cannot substitute for it.

Actual required-proof subjects, CPU source/signature/effect identity and signed
receipt binding remain required. Matching request subjects are not proofs. The
source translation must match exactly one memory effect and one value expression;
these counts restrict the supported fragment rather than proving equivalence.

The helper introduces no second traversal, heap storage, owner field, lifetime,
public API or new authority. It preserves the original ledger and retained floor.
For B blocks and O operations its complete operand scan charges `32+B+1024*O`;
the supported join's increase over Source257 is `28+512*O`. Existing receipt
allocation/order/keys, protected runtime lease and pointer-based ownership remain.
Compilation still ends at `Incomplete`, with all nine checks pending and zero
unconditional TotalView credit.

The documentation distinguishes output O, extent N and point i: lifting a CPU
point applies only where `i < N`. Ranked views have no physical pointer/stride
fields; byte interpretation comes from checked canonical facts. `N <= G`, inactive
axes, actual packed arguments, valid memory and GlobalLaunch address
representation remain external premises, including at N=0.
