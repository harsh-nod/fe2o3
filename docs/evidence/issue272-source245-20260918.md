This is partial infrastructure, not milestone completion. All full M0-M7
milestones remain open, no GPU ran, and the qualified-pair count remains zero.
The ordinary-source compiler parent still fails at ownership verification.

## Implementation

- The protected process supervisor uses four short, bounded idle polls after
  progress, then returns to its existing 2 ms backoff. Its admission, process,
  executable, mapping, descriptor, signal, output and deadline checks are unchanged.
- Rejected Verus results retain exit/signal and escaped stream excerpts. Each
  excerpt is limited to 1,024 input bytes, with original length and truncation
  reported. The exact positive-output acceptance predicate is unchanged.
- Only reachable typed IEEE-congruence expressions request the existing IEEE
  declaration. Integer-only individual and aggregate proofs no longer inherit
  an unused `uninterp` declaration rejected by production's `--no-cheating`.
- Exact integer proof snapshots and their script hashes are updated. The
  standalone fixture script now also uses `--no-cheating --num-threads 1`.
- A protected-runtime regression requires the real public runtime lease,
  verifies two integer examples, and requires an assertion-failure rejection
  when the second output changes from 9 to 10. It creates no receipt authority.

IEEE proofs that require the opaque declaration remain unsupported by the
strict runtime. This does not establish IEEE value semantics, numerical error
bounds, machine refinement, or the default production proof publisher.
