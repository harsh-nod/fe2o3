## Production Invariant

Rustc may pass a capture-free closure directly as a zero-sized constant without
retaining any closure local. The old scanner missed that value while the call
collector correctly recorded its argument ordinal. The complete-census check
then rejected the missing provenance. This checkpoint fixes the observation;
it does not skip the ordinal or relax the census.

The existing use scanner now classifies constants with the live monomorphized
rustc type. A private observation accepts only `Const::Val(ZeroSized, ...)`
whose normalized type is a concrete closure with no captures, a valid call kind,
zero size and fields, inhabited layout, permitted alignment and no drop glue.
It binds the exact caller, block, source argument and type identity. There is no
CTFE fallback, invented local, new wire schema or serialized authority token.

Before seeding the formal's local origin, the flow resolver reobserves the
constant, checks the live callee and argument roster, and preserves the existing
actual/signature/formal type relation. The seed is ORed with existing origins;
an external parameter cannot be relabelled device-local. Duplicate records reject
before set conversion can hide them. Import reconstructs the graph and origins
from live MIR using the same cumulative collection/import work ledger.

Constant-only callers no longer depend on a local-only presence precheck.
Unsupported assignment, tail-call, assertion and assembly uses still reject in
the same scan. Ordinary unit and function constants are not closure origins.
The existing environment and static-use limits remain in force.

The published call-preparation/placement merge also preserves borrowed aggregate
argument preparation and records allocation, initialization and call locators at
their emitted block positions. A nonzero-placement regression checks the actual
Alloca, Store and Call operands while source anchors remain local coordinates.
Independent borrowed replay's identity-block restriction is not broadened.
