# Retained Shared source engine qualification — 2026-09-29

This private component joins the original alias, liveness, read and observer
algorithms into a statement-driven retained owner. It is not an ordinary
compilation route or a complete source/SSA acceptance proof.

## Implemented continuation

Rvalue production retains the actual right-hand side and selected aliases.
Installation holds the removed destination, current alias, replacement fields
and unconsumed drain across work or storage refusal. Statements and terminators
follow the original source order, including candidate insertion and read flags
before their original fallible operations.

The original liveness completion and expiry walk run before exhaustion fallback.
Completed block data, accepted candidates and a separate empty fallback remain
owned until drop. An ignored original error terminalizes the retained engine;
later calls cannot clear pending arenas, replace the first failure, or restart
semantic work. Successful final access checks the exact function/type pair and
the same physical Budget, Work lifetime and owned-credit counter.

Dynamic buffers are attached before excess-capacity admission. Typed frames and
logical collection envelopes are charged on the original ledger; these are not
hard RSS or allocator-OOM guarantees. Partial allocations remain attached on a
failed excess charge, without claiming those excess bytes were funded.
