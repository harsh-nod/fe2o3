construction, refusal ordering and logical assertion counters remain distinct
from additional strict resource charges. Strict analysis borrows the actual
prepared source graph and tables, not an empty graph or an assumed decision
mask. Model payload cloning, comparison, collection growth and recursive
value/result/error frames are prepaid. The source-level frame envelope is a
logical accounting bound, not a measurement of machine stack use or RSS.
