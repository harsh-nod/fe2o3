# Support

fe2o3 is a developer preview maintained on a best-effort basis. There is no
guaranteed response time, compatibility window, or production support SLA.

Use the [canonical issue tracker](https://github.com/harsh-nod/fe2o3/issues/new/choose):

- Choose **Question or support request** for installation and usage questions.
- Choose **Bug report** for a reproducible defect.
- Choose **Feature request** for a proposed capability or workflow.

Before filing, search existing issues and include the fe2o3 commit, pinned Rust
toolchain, operating system, GPU model and GFX target when relevant, and the
smallest reproducible kernel or KIR input. Remove credentials, proprietary
source, hostnames, device serials, and sensitive profiler data.

The tutorial site at <https://harsh-nod.github.io/fe2o3-kernels/> contains
worked examples. The source repository's support matrix and project status are
authoritative when a tutorial and the current checkout differ.

Do not use a public issue for a suspected vulnerability. Follow
`SECURITY.md` instead.

The `powderluv/fe2o3` repository is the code mirror and the protected parity
protocol's design-bound repository. The protocol is not currently deployed or
qualified there. The mirror is not a separate support or release channel.
