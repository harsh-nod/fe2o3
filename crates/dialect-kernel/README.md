# dialect-kernel

`dialect-kernel` is the target-neutral Pliron shell that owns structured
algorithm semantics. Its bounded D0 surface consists of an algorithm type, an
iteration-domain attribute, an algorithm-root operation, and an ownership
interface.

The shell does not lower operations, choose schedules or compilers, describe a
hardware target, produce artifacts, or grant proof, publication, load, tuning,
or launch authority. Its Pliron values and printed syntax are not durable
fe2o3 identities.
